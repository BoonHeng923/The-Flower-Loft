# The-Flower-Loft
## Overview
**The Flower Loft** is an e-commerce website designed to simulate an online flower shop.
It showcases our understanding of HTML, CSS, and JavaScript, emphasizing responsive design, user interactivity, and clean layout principles.

The website theme embodies soft pastel tones and a minimalist floral aesthetic, reflecting elegance, serenity, and emotional connection — key to appealing to customers seeking floral gifts for special occasions.

## Objectives
- Design a visually cohesive and user-friendly e-commerce website.
- Ensure cross-device responsiveness (desktop, tablet, mobile).
- Apply interactive features using JavaScript for better user engagement.
- Maintain consistent branding and color palette.
- Demonstrate teamwork through collaboration and version control practices.
  
## Key Features
### Login Page
- **Form Validation with JavaScript:** Ensures that both email and password fields are filled before submission.
- **Custom Alert Messages:** Shows informative pop-up messages for missing input fields.
- **Password Masking:** Uses type="password" for security.
- **Remember Me Option:** Checkbox allowing users to stay signed in.
- **Forgot Password Link:** Placeholder link for future password recovery implementation.

### Sign Up Page
- **Real-Time Input Validation:**
  1. Checks for empty fields (first name, last name, email, password).
  2. Validates proper email format.
  3. Ensures matching passwords before form submission.
- **Instant Feedback:** Displays “Password does not match” dynamically in red text when mismatched.
- **Success Message Popup:** Alerts users upon successful form completion.

### Home Page
- Image slider showcasing floral collections.
- Category sections (Best Sellers, Love & Romance, Grand Opening, Graduation, Get Well Soon).
  
### About Us Page
- Background image banner.
- Sections:
  1. **Our Story:** Introduces company history and inspiration.
  2. **Our Promise:** Describes service values and quality standards.
  3. **Meet Our Team:** Features team introduction with photos and descriptions.

 ### Products Page
 - Displays flower categories like Best Sellers, Love & Romance, Grand Opening, Graduation, Get Well Soon, and Add-Ons.
 - Best-selling items are labeled with a gold “Best Seller” tag.
 - Grid rearranges automatically for mobile screens using media queries.

### Product Details Page
- Displays a large image of the selected flower bouquet.
- Clicking on small thumbnails dynamically updates the main image using JavaScript.
- Users can specify quantity with built-in numeric input validation.

### Workshops Page
- Describes different workshop tiers (Beginner and Advanced).
- licking thumbnails changes the main workshop image dynamically using JavaScript.

### Reviews Page
- Each review is presented in a rounded rectangular card with white background.

### Contact Us Page
- Comprehensive Input Validation:
  1. **Name field:** Accepts only alphabets and spcaes.
  2. **Email field:** Must match the pattern xxx@gmail.com.
  3. **Phone field:** Must follow format +60123456789.
  4. **Subject and message fields:** Required for submission.
- **Popup Message When Submit:** Displays a “Thank You” confirmation modal when message submission is successful.

### Promotion Popup Box
- Validates name and email before submission.
- Uses closePopup() JavaScript function to hide the box instantly.
